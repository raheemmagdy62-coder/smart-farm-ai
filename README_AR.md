## التشغيل (PowerShell، جوه فولدر المشروع)
```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install torch torchvision open_clip_torch      # لو ما اتثبتتش قبل كده
python -m streamlit run app.py
```
- **أول صورة** بترفعها بتنزّل النموذج (حجم كبير، مرة واحدة). راقب الطرفية.
- لو كان عندك `app.py` قديم: خد نسخة منه الأول (`Copy-Item app.py app_old.py`) قبل ما تنسخ الملفات الجديدة.
- **مهم:** انسخ المجلد كله (بما فيه `data` و`.streamlit`) جنب `.venv`، مش `app.py` وحده.

## قياس دقة التعرف (أهم خطوة علميًا)
رتّب صورك الحقيقية كده:
```
my_photos/grape/  my_photos/guava/  my_photos/pear/
my_photos/other_fruit/   (أوراق أي نبات آخر)
my_photos/not_leaf/      (أيدي، تربة، خلفيات)
```
ثم:
```powershell
python evaluate_plants.py my_photos
```
بيطبع Accuracy وPrecision وRecall وF1 ومصفوفة الالتباس ومعدل القبول الخاطئ ومعايرة الثقة، ويحفظ ملف `evaluation_results.csv`.
**لا تضبط الحدود (`HIGH_CONFIDENCE` وغيرها) على نفس صور الاختبار النهائي.**

## تحديثات النسخة 5
- أُضيفت إرشادات رعاية عامة بعد التعرف على الأنواع الموجودة في القاموس، مع معلومات أكثر تخصيصًا للعنب والجوافة والكمثرى. الإرشادات العامة لا تضمن زيادة المحصول ولا تستبدل التوصية المحلية.

- لم تُحذف أي وظيفة من الوظائف الأربع، ولم نغيّر منطق مستشار المحاصيل في هذه النسخة.

## حدود معروفة (اقرأها قبل العرض)
1. دقة التعرف **لم تُقَس** بعد. درجة التفضيل ليست دقة.
2. النموذج لم يُدرَّب على أوراقنا. القاموس الموسّع (54 نوعًا) يزيد احتمال اللخبطة بين الأنواع المتقاربة.
3. مستشار المحاصيل يحتوي على 23 محصولًا في جدول مواعيد FAO-56 (مناخات مشابهة لمصر وليست كلها مصرية؛ القطن والفاصوليا الخضراء فقط موسومان بمصر) وعلى جدول ملوحة FAO. لا يستخدم التربة/الصرف/pH بصورة مكتملة ولا يتوقع إنتاجية أو أرباحًا. لا تدّعِ أنه يغطي كل محصول بعد.
4. قاعدة فحص الأمراض تحتوي على 12 حالة للعنب والجوافة والكمثرى فقط؛ إرشاداتها أولية ومن مصادر دولية ولم يراجعها مهندس زراعي مصري بعد. الأسئلة الإضافية تحسّن جمع المعلومات لكنها لا تجعل النتيجة تشخيصًا مؤكدًا. لا تقدم وصفات مبيدات أو جرعات، ولا تعتمد على نتيجة التطبيق وحدها للعلاج.
4. الجوافة ليس لها معامل Kc في FAO-56، والكمثرى ليس لها حد ملوحة رقمي في الجدول.
5. تحديد الموقع التلقائي من الجهاز غير مفعّل (يحتاج HTTPS). الموقع بالاسم المكتوب.
6. عند الوصول من الموبايل على `http://IP:8501` قد لا تعمل كاميرا المتصفح؛ استخدم زر رفع الصور.
7. لم أستطع تشغيل Streamlit ولا BioCLIP ولا استدعاء Open-Meteo في بيئتي (بدون إنترنت)، فهذه الأجزاء لم تُجرَّب فعليًا.


## فتح الموقع من الموبايل أو أي جهاز
1. اللابتوب والموبايل على **نفس شبكة الواي فاي**. شغّل الموقع هكذا:
   ```powershell
   python -m streamlit run app.py --server.address 0.0.0.0
   ```
2. في PowerShell اكتب `ipconfig` وخذ رقم **IPv4 Address** (مثل `192.168.1.20`).
3. من متصفح الموبايل افتح `http://192.168.1.20:8501` (بدّل الرقم برقمك).
4. لو ويندوز سأل عن Firewall اسمح للشبكات **الخاصة** فقط.
5. أي جهاز آخر على نفس الشبكة يقدر يفتح نفس الرابط، وليس هناك كلمة سر، فلا تستخدم شبكة عامة غير موثوقة.
6. لو شبكة المكان تمنع الأجهزة من رؤية بعضها: افتح **Hotspot** من الموبايل ووصّل اللابتوب عليه.
7. الموبايل لا ينفّذ التحليل: كل الحساب على اللابتوب. وجهاز لابتوب مقفول أو نائم = الموقع لا يعمل.
8. لفتحه من خارج الشبكة تحتاج نفقًا أو استضافة. لم أجرّب أي خيار منها، وBioCLIP ثقيل على الاستضافات المجانية، فاتركه لآخر مرحلة.

## فحص الأعراض بالأسئلة (تبويب 🩺)
- بيسألك عن الأعراض (وجه الورقة العلوي والسفلي، الأفرع، الثمار...) ويرتّب الاحتمالات من قاعدة معرفة مصدّرة.
- مش تشخيص نهائي، ومش بيحسب احتمالات؛ بيعدّ علامات التطابق والتعارض ويوضح ما ينقص.
- لإضافة مرض: افتح `data/disease_kb.json` وأضف عنصرًا في `diseases` على نفس الشكل: `expects` (علامات strong/weak/contra) و`management` و`sources`. **كل نصيحة لازم لها مصدر (source + url)**. شغّل الاختبارات بعدها (`python -m unittest discover -s tests`): بتتأكد إن كل مرجع موجود وإن كل نصيحة لها مصدر وإن ما فيش جرعات.
- الأسماء والجرعات التجارية للمبيدات **غير معروضة عمدًا**.
